# HFS/HFSX Image Analysis

A Mac OS X Tiger forensic image (`Mac_OS_X4_Tiger.001`) was examined using FTK Imager.

The analysis included identifying the file-system type and recording volume properties such as sector size, block size, sector count, and cluster count. The image was then navigated to identify the primary user account and review user directories including Documents and Desktop.

This exercise demonstrated that forensic examiners must be comfortable moving between different file-system families and recognizing operating-system-specific structures.
